# 강원 시범 권역 콘텐츠 초안 (0단계)

- 계획서: `2026-11-26-gangwon-pilot-plan.md`
- 상태: **초안. 팀 검토 필요.** 장소·사실 정보와 좌표는 모두 "확인 필요" 상태다. 좌표는 팀이 지도 앱에서 인증 지점(입구·광장 등 사람이 실제로 서는 곳)을 찍어 채운다.
- 마스코트는 자체 캐릭터다. 각 시·군의 공식 마스코트가 따로 있으므로, 그림을 그릴 때 이름·모양이 겹치지 않는지 확인한다.

## 공통 규칙

- 마스코트 말투: 반말, 짧은 문장, 문장 끝에 그 캐릭터만의 말버릇 하나.
- 퀘스트 안내문: 3~4문장. ① 어떤 곳인지 ② 왜 가 볼 만한지 ③ 인증 지점이 어디인지.
- 퀘스트 종류: 명소(spot) · 먹거리(food) · 이야기(story).
- 인증: 인증 지점 반경 200m 안, 위치 정확도 100m 이내.
- 그림: 둥근 실루엣, 앱 새 테마 색(코랄·민트·밝은 주황)과 어울리게. 잠긴 상태용 실루엣도 함께.

## 1. 춘천시 (51110)

**마스코트 콘셉트: "물안개 수달"(가칭)**
- 호수 도시의 아침 물안개를 머리에 이고 다니는 동그란 수달.
- 말버릇: "~했달!"
- 미리보기 문구: "호수 위로 안개가 피면 내가 나타난달. 춘천에 오면 꼭 찾아줘!"

| 종류 | 장소 후보 | 안내문 초안 | 인증 지점 |
|---|---|---|---|
| 명소 | 소양강 스카이워크 | 강 위로 길게 뻗은 유리 길이야. 발아래로 강물이 보여서 조금 아찔하달! 입구 쪽에서 위치를 확인해줘. | 확인 필요 |
| 먹거리 | 명동 닭갈비골목 | 춘천 하면 닭갈비지! 골목 하나에 닭갈비 집이 쭉 모여 있달. 골목 입구에서 인증하고 한 판 먹고 가! | 확인 필요 |
| 이야기 | 김유정문학촌 (실레마을) | 소설 「봄·봄」을 쓴 작가가 자란 마을이야. 소설 속 장소들이 마을 곳곳에 남아 있달. 문학촌 앞마당에서 인증해줘. | 확인 필요 |

## 2. 원주시 (51130)

**마스코트 콘셉트: "한지 종이학"(가칭)**
- 원주 한지로 접은 동그란 종이학. 바람이 불면 살짝 출렁거린다.
- 말버릇: "~할랑!"
- 미리보기 문구: "흔들흔들 출렁다리 건너편에서 기다릴랑. 원주에서 만나!"

| 종류 | 장소 후보 | 안내문 초안 | 인증 지점 |
|---|---|---|---|
| 명소 | 소금산 출렁다리 | 산과 산 사이에 걸린 높은 다리야. 한 걸음마다 출렁출렁해서 심장이 두근거릴랑! 다리 입구 매표소 근처에서 인증해줘. | 확인 필요 |
| 먹거리 | 치악산 황골엿 (판매처 확인 필요) | 쌀과 옥수수로 오래 고아 만든 엿이야. 쫀득하고 달콤할랑! 판매처 앞에서 인증해줘. | 확인 필요 |
| 이야기 | 원주 한지테마파크 | 내가 태어난 원주 한지 이야기를 볼 수 있는 곳이야. 종이가 어떻게 만들어지는지 보면 신기할랑. 입구에서 인증해줘. | 확인 필요 |

## 3. 강릉시 (51150)

**마스코트 콘셉트: "몽돌 순두부"(가칭)**
- 바닷가 몽돌처럼 동글고 순두부처럼 말랑한 캐릭터. 머리에 커피콩 하나.
- 말버릇: "~하는 거 몽!"
- 미리보기 문구: "바다 냄새랑 커피 냄새가 같이 나는 곳에 있는 거 몽. 강릉으로 와!"

| 종류 | 장소 후보 | 안내문 초안 | 인증 지점 |
|---|---|---|---|
| 명소 | 경포대·경포해변 | 호수와 바다를 한 번에 볼 수 있는 곳이야. 해 질 녘에 오면 하늘이 예쁜 거 몽! 경포해변 중앙 광장에서 인증해줘. | 확인 필요 |
| 먹거리 | 초당 순두부마을 | 바닷물로 굳힌 부드러운 순두부를 먹을 수 있는 마을이야. 나랑 닮은 맛인 거 몽! 마을 입구에서 인증해줘. | 확인 필요 |
| 이야기 | 오죽헌 | 신사임당과 율곡 이이가 태어난 집이야. 검은 대나무(오죽)가 자라서 이름이 오죽헌인 거 몽. 정문에서 인증해줘. | 확인 필요 |

대체 후보: 먹거리로 안목해변 커피거리.

## 4. 속초시 (51210)

**마스코트 콘셉트: "갯배 오징어"(가칭)**
- 갯배 줄을 잡아당기며 노는 동그란 오징어. 다리 여덟 개 대신 짧은 다리 네 개.
- 말버릇: "~한다 징!"
- 미리보기 문구: "줄 당기면 배가 움직인다 징! 속초 바닷가에서 같이 놀자."

| 종류 | 장소 후보 | 안내문 초안 | 인증 지점 |
|---|---|---|---|
| 명소 | 영금정 | 파도가 바위에 부딪히는 소리가 거문고 소리 같다고 이름 붙은 곳이야. 바다 위 정자까지 걸어갈 수 있다 징! 정자 입구에서 인증해줘. | 확인 필요 |
| 먹거리 | 속초관광수산시장 | 닭강정, 오징어순대 같은 먹거리가 가득한 시장이야. 배고프면 여기다 징! 시장 정문에서 인증해줘. | 확인 필요 |
| 이야기 | 아바이마을·갯배 | 전쟁 때 북쪽에서 내려온 사람들이 모여 살던 마을이야. 줄을 당겨 건너는 갯배를 타 볼 수 있다 징. 갯배 선착장에서 인증해줘. | 확인 필요 |

## 팀이 할 일

1. 마스코트 4종 이름 확정 (가칭 교체 여부)과 그림: 기본 1장, 잠긴 상태 실루엣 1장. 정사각형 PNG 512px 권장 (앱에서는 줄여서 표시).
2. 퀘스트 12곳 사실 확인: 운영 여부, 휴무일, 입장료 여부, 안내문 내용.
3. 인증 지점 좌표 12개: 위도·경도 소수점 다섯째 자리까지.
4. 확인이 끝나면 이 문서를 고치거나 표를 채워서 넘겨주면, 앱 데이터 파일(`data/guide.js`)로 옮긴다.
